# داقش

لعبة ورق خليجية أساسها المساومة والبلوف. موقع ثابت، ملف واحد، بدون باك إند ولا قاعدة بيانات ولا تسجيل حساب.

## الأوضاع

- **مع أصحابي** — غرفة بكود من 5 أرقام، كل واحد من جهازه (جوال أو لاب توب). الرسائل تمر عبر وسيط MQTT عام (EMQX/HiveMQ) — ما يحتاج حساب ولا سيرفر، ويتجاوز مشاكل شبكات الجوال.
- **غرف مفتوحة** — لو ما عندك أحد جاهز، تقدر تخلي غرفتك عامة فتبين لأي واحد يفتح الصفحة، أو تتصفّح الغرف اللي ناقصها لاعبين وتدخل عليها. الغرفة تطلع من القائمة أول ما تبدأ اللعبة أو يطلع المضيف.
- **ضد البوتات** — ثلاث مستويات، الصعب يبلف ويشتري سكوتك.
- **مرّر الجوال** — 4 إلى 13 لاعب على جهاز واحد، مع شاشة حجب قبل كل دور.

يفوز أول لاعب يوصل مليون. ولو أحد فلّس وبقيتم اثنين (أو ثلاثة إذا بدأتم 7 فأكثر)، الأعلى رصيداً يفوز.

## النشر على Netlify

### الطريقة الأسرع — سحب وإفلات

افتح [app.netlify.com/drop](https://app.netlify.com/drop) واسحب مجلد `dagesh-site` كامل. يطلع لك رابط فوراً.

### من الطرفية

```bash
npm i -g netlify-cli
```

بعدها من داخل المجلد:

```bash
netlify deploy --prod --dir .
```

أول مرة بيفتح لك المتصفح تسجّل دخولك في Netlify، وبيسألك تنشئ موقع جديد.

### اختيار الدومين المجاني

```bash
netlify sites:update --name dagesh
```

يصير الرابط `https://dagesh.netlify.app`. لو الاسم محجوز جرّب `daqesh` أو `dagesh-game` أو `mdagesh`. تقدر تغيّره كمان من لوحة Netlify: **Site configuration → Domain management → Options → Edit site name**.

## دعوة الأصحاب

الرابط يقبل كود الغرفة مباشرة:

```
https://dagesh.netlify.app/?room=12345
```

أرسل هذا للي تبيه، ويدخل الغرفة على طول بدون ما يكتب الكود.

## ملاحظة أمانة

جهاز المضيف هو اللي يوزّع الورق ويدير الجولة، فتقنياً يقدر يشوف ورق الجميع. للعب بين أصحاب هذا مقبول — زي اللي يمسك الشدّة في الواقع — بس خلّوا المضيف واحد تثقون فيه.

لو تبي توزيع محمي ما أحد يقدر يشوفه، تحتاج سيرفر يوزّع الورق ويخفيه بـ Row Level Security. الخطة كاملة في `Dagesh_Multiplayer_Prompt.md`.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | اللعبة كاملة — منطق وواجهة وشبكة |
| `netlify.toml` | إعدادات النشر والهيدرز |

لا توجد اعتماديات تُثبَّت. المكتبة الوحيدة الخارجية هي mqtt.js وتُحمّل من cdnjs.
